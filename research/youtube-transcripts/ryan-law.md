# Ryan Law — YouTube Transcript Notes

## Video: How to Automate Blog Writing with AI (with Tim Soulo)
- **Expert:** Ryan Law (with Tim Soulo, CMO of Ahrefs)
- **Source:** https://www.youtube.com/watch?v=iVZrVeESnFQ
- **Published:** May 2026
- **Collected:** August 2, 2026

### Summary
Live demo of the full AI content pipeline at Ahrefs. Shows the system going from keyword input to publish-ready article in approximately 8 minutes.

### Key takeaways
- The pipeline chains 23 skill files sequentially using Claude Code
- Each skill file is a Markdown document that instructs the LLM on one editorial step
- Intermediate outputs (outline, research brief, draft) are saved to separate files for debugging
- Tim Soulo emphasizes that the real value is in the 23 custom skill files — that is where the editorial standards live
- The system uses Ahrefs MCP integration to pull real keyword data, SERP analysis, and competitor information instead of relying on LLM-generated data
- Ryan demonstrates how a failed step can be diagnosed and rerun from the last good checkpoint
- Explicitly stated: this system mirrors a process built from 14 years of content marketing experience — the AI executes the process, it did not create it
